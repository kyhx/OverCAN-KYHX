> **本文是引脚分配的落地手册**：给出核心机（ESP32-S3）与两个节点（STM32F103C8T6）的**完整**引脚分配、依据、
> 冲突分析与"未分配引脚"清单。设计规格见 [项目文档.md](./项目文档.md) §4；协议字段见 [protocol.md](./protocol.md)。
>
> **状态**：分配已定稿，但**未经硬件验证**（无实物测量）。标注 ⚠️ 的条目是上电前必须实测/核对的点。
> **单一来源**：代码里的引脚常量只能来自 `firmware/node1/include/node1_config.h`、`firmware/node2/include/node2_config.h`
> 与本文表格；驱动代码**不得出现魔数**。改引脚 = 改这三个地方之一。

## 一、分配原则（先定规则，再填表）

| # | 原则 | 理由 |
| --- | --- | --- |
| P1 | **SWD（PA13/PA14）永不占用** | 节点无 USART 时它是唯一的烧写与调试通道；丢了就要拆板接复位线 |
| P2 | **CAN 用芯片默认引脚**（STM32 用 PA11/PA12，ESP32 用 GPIO4/5） | 避免重映射带来的 AFIO 配置与可移植性负担，减少一处出错点 |
| P3 | **定时器资源按用途隔离**：舵机/电机 PWM 各占独立定时器 | 同定时器改频率会互相影响；车身类执行器不应共享时基 |
| P4 | **ADC 引脚绝不接 5V**（即使标称 FT 的脚） | 模拟模式下不得超过 VDDA，这是强制项不是优化项 |
| P5 | **strapping / 启动相关引脚不接按键或强驱动负载** | 复位瞬间被拉低会改变启动模式（详见风险表 R-1/R-2） |
| P6 | 优先把**外设固定在硬件外设引脚**上，其余信号用普通 GPIO | 便于后续换 MCU 或重映射 |
| P7 | 每块板**至少留 1 个可用 GPIO** | 现场调试/加装指示灯的救命脚 |
| P8 | 引脚分配**只写在配置头文件**里 | 换板（C8T6→CBT6）或改板时一处生效 |

**电气前提**（与引脚强相关，必须一并满足）：

- **逻辑电平**：ESP32-S3 与 STM32 均为 3.3V；TJA1050 是 **5V 器件** → 收发器接 5V 轨，RXD/TXD 电平处理见 [项目文档.md](./项目文档.md) §9.1。
- **供电分轨**：逻辑轨 3.3V/5V 与动力轨（电机 VM、舵机 5V）**独立供电 + 共地**。
- **CAN 物理层**：总线两端各 120Ω（建议分裂终端 2×60Ω+4.7nF），CAN_H/L/GND **焊接或压接**，支线 <0.3m。

### 2.2 不可用 / 慎用引脚（分配表的边界）

| 引脚 | 状态 | 原因 |
| --- | --- | --- |
| **GPIO33 ~ GPIO37** | ❌ **不可用** | N16R8 的 **Octal PSRAM** 占用（33=SPIIO4 … 37=SPIDQS）。**若改用 Quad PSRAM 型号（N8R2）这 5 个脚即空闲** |
| GPIO26 ~ GPIO32 | ❌ 不可用 | 模组内部接 SPI Flash，未引出 |
| GPIO19 / GPIO20 | ⚠️ 保留 | 原生 USB D-/D+，占用后无法 USB 烧写 |
| **GPIO0 / GPIO3 / GPIO45 / GPIO46** | ⚠️ 不用 | strapping 引脚，复位电平影响启动模式 |
| GPIO43 / GPIO44 | ⚠️ 保留 | UART0 调试串口（`ESP_LOG` 默认输出） |
| GPIO39 ~ GPIO42 | ⚠️ 保留 | JTAG（MTCK/MTDO/MTDI/MTMS）调试用 |
| GPIO38 / GPIO48 | ⚠️ 不确定 | 板载 WS2812 的引脚**随 DevKitC-1 版本变化**，不可当确定备用脚 |

> **结论**：GPIO9 是唯一"确定可用"的备用脚。若后续需要更多引脚，**换 N8R2（Quad PSRAM）可一次释放 GPIO33~37 五个脚**——
> 本项目无大词汇量语音模型，2MB PSRAM 足够，这笔账很划算（详见 §6 的采购决策）。

### 2.3 引脚预算小结

已用 15 个（CAN 2 + I²C 2 + I²S 5 + SPI 4 + 编码器 2 + 按键 3 = 18 个信号，其中编码器与按键不共用）→ 实际占用
**GPIO1、2、4、5、6、7、8、10、11、12、13、14、15、16、17、18、21、47**，备用 1 个（GPIO9）。

### 3.2 三个待决冲突（**上电前必须选一个**）

| 冲突 | 现状 | 方案 A（推荐） | 方案 B |
| --- | --- | --- | --- |
| **R-3 调试口 vs 电机 PWM** | PA9 被 PWMB 占用 → 无 USART1；PB10/PB11 又被电机 B 方向占用 → USART2 也没了 | **把两路 PWM 移到 PB6/PB7（TIM4_CH1/CH2）**，方向脚改 PB0/PB1 与 PB10/PB11 不变 → 释放 PA9/PA10 作 USART1 调试口 | 保持现状，调试一律走 **SEGGER RTT**（走 SWD，不占引脚） |
| **R-4 PB10/PB11 双重占用** | 文档既让它们做电机 B 方向，又建议做 USART3 调试口 | 方向脚留 PB10/PB11；调试用 USART1（方案 A 之后可用） | 方向脚改 **PB14/PB15**，PB10/PB11 留给 USART3 |
| **R-5 JTAG 脚做 GPIO** | PB3/PB4/PA15 是 JTAG（不是 SWD） | 本分配**不用**这三个脚，需要时再关 JTAG | 若要用，须关 SWD 之外的 JTAG 位（只留 SWD，仍可烧写） |

> **推荐落地**：R-3 选方案 A。理由：节点一无 USART 会让"阶段 1 单节点打通"的调试成本陡增，
> 而把 PWM 从 TIM1 挪到 TIM4 只是改两行配置，还能顺手摆脱 TIM1 高级定时器的 MOE 坑。
> 若最终选方案 B（保留 PA9），则**必须**在配置头里注释清楚"无调试串口，调试走 RTT"。

### 4.2 为什么舵机放在 TIM3（PA6）而不是 TIM1（PA8/PA9）

1. **摆脱高级定时器**：TIM1 输出默认关闭，必须 `TIM_CtrlPWMOutputs(TIM1, ENABLE)` 使能 MOE，漏了就是"配置全对但没波形"的经典坑。
2. **定时器隔离**（原则 P3）：舵机 50 Hz 与电机 20 kHz 频率差 400 倍，共享时基会让参数计算互相牵制。
3. **释放 PA8/PA9**：PB 侧还可留作扩展。

> ⚠️ **常见误解澄清**：同一 TIM1 的两路通道**共用时基**，因此"PA8 做 20 kHz 电机 PWM、PA9 做 50 Hz 舵机"是**不成立的**；
> 但"两路都是 50 Hz 舵机"完全没问题。文档早期版本把"同频无冲突"错写成了"必然冲突"，两处都需以本条为准。

## 五、跨板一致性与总线侧

### 5.1 CAN 总线拓扑与终端

| 项 | 规定 |
| --- | --- |
| 速率 | 500 kbps（面包板原型先用 **125 kbps**） |
| 采样点 | **87.5%**（STM32：P=9/BS1=6/BS2=1/SJW=1；ESP32：brp=20/tseg_1=6/tseg_2=1/sjw=1） |
| 终端 | **物理两端各 120Ω**（建议分裂终端 2×60Ω + 4.7nF 到地）；中间节点**不加** |
| 支线 | **< 0.3 m** |
| 接线 | CAN_H / CAN_L / GND **必须焊接或压接**，不可用面包板杜邦线 |
| 布线 | 差分线**绞线**走线，与电机/舵机动力线**分开** |

**三块板在总线上的位置**：核心机（ESP32-S3）与节点一在链路两端（各装一只终端电阻），节点二居中（不装）。
若日后把节点二挪到末端，终端电阻要跟着挪——**终端接的是"线的物理两端"，不是"某块特定的板"**。

### 5.2 I²S 共享时钟（核心机专用）

麦克风（MS4030/INMP441）与功放（MAX98357）**共享 BCLK/WS 时必须挂在同一 I²S 端口**，两条合法路径：

| 方案 | 引脚数 | 说明 |
| --- | --- | --- |
| (a) 单端口全双工，共享 BCLK/WS | 本节 2.1 表所用（4~5 脚） | 省引脚；需保证 TX/RX 槽位与位宽配置一致 |
| (b) 双端口独立（I2S0 收 / I2S1 发） | 6 脚 | 更简单，无全双工耦合约束；ESP32-S3 有 2 个 I²S 控制器 |

> INMP441 输出 24 bit 左对齐装在 32 bit 容器里，读取后**必须右移 8 位**，否则音量异常偏小。

## 六、风险与上电前检查清单

| # | 风险 | 影响 | 处置 |
| --- | --- | --- | --- |
| **R-1** | ~~按键接在 GPIO8/GPIO9 而它们可能是 strapping 脚~~ → **已核实：不是风险** | ESP32-S3 的 strapping 引脚只有 **GPIO0 / GPIO3 / GPIO45 / GPIO46**，GPIO8/GPIO9 **不在其中** | ✅ **无需处置**（本条保留作"曾经误判"的记录）。真正的纪律是：**GPIO0/3/45/46 上不要加强驱动或外部上下拉**，否则会改变启动模式与 VDD_SPI 电压 |
| **R-2** | **GPIO47（BTN3）复位后是"输入使能、无内部上下拉"的悬空状态** | 悬空输入电平漂移 → 按键电平不确定，可能上电瞬间即被读成"按下" | ✅ 使能内部上拉（按键低有效）或在按键两端加外部 10k 上拉；**下板前用万用表确认复位期间 BTN3 为高** |
| **R-3** | **节点一 PA9 被电机 PWM 占用** | 失去 USART1；叠加 PB10/PB11 占用后**两节点都没有调试串口** | ✅ **已定稿方案 A**：PWM 移到 **TIM4 的 PB6/PB7**，释放 PA9/PA10 作 USART1（代码已改，见 `node1_config.h`） |
| **R-4** | **节点一 PB10/PB11 既做电机 B 方向、又被建议做 USART3** | 配置互相覆盖，实际只有一个生效 | ✅ 定为**电机 B 方向**；调试口改用 USART1（PA9/PA10） |
| **R-5** | **PA15 / PB3 / PB4 是 JTAG 脚**（复位默认 JTDI/JTDO/NJTRST） | 直接当 GPIO 用**没有任何输出**（静默失效），且释放前改 IOPORT 配置无效 | ✅ 本分配不使用这三个脚。**若将来要用**：先开 AFIO 时钟 → 写 `AFIO_MAPR` 的 `SWJ_CFG=010`（关 JTAG-DP、留 SW-DP）→ 再配 GPIO；**SWD 仍完全可用**。⚠️ `SWJ_CFG` 是**只写位**（读回值未定义），禁止对它做读-改-写；HAL 宏为 `__HAL_AFIO_REMAP_SWJ_NOJTAG()` |
| **R-6** | **PA11/PA12 兼作 USB D-/D+**；Blue Pill 板载常带 USB 相关上下拉/跳线 | CAN 使用这两个脚后板上 USB 不可用；板上既有电阻可能干扰总线 | 相机检查 PA12 是否焊有上拉电阻/跳线。**CAN 备选引脚 = PB8/PB9**（`CAN_REMAP=10`，LQFP48 的 pin 45/46）。⚠️ **PD0/PD1 在 48 脚封装上不可用**——RM0008 明文规定 Port D 的 CAN 重映射在 36/48/64 脚封装上不可行 |
| **R-7** | **PA0~PA7 / PB0 / PB1 这 10 个 ADC 引脚不是 5V 容忍引脚** | 输入上限 VDD+0.3V（3.3V 供电约 3.6V），绝对最大 4.0V；超压可能损坏引脚或读数全错 | 模拟模块统一 3.3V 供电；若必须 5V 则**外部分压**（强制项）。⚠️ 注意：**模拟模式下"FT/5V 容忍"不适用**，即使该脚在数字模式下标 FT，模拟输入也不得超过 VDDA |
| **R-8** | **PA6 已被节点二舵机占用，PA0/PA1 被 ADC 占用** | 想加编码器做闭环 PID 时无脚可用 | 编码器需 TIM 编码器模式（TIM2 的 PA0/PA1，或 TIM3 的 PA6/PA7）：**必须重新分配**——把光敏从 PA0/PA1 挪到 PA4/PA5，或把舵机挪到 TIM4/PB6+PB7 |
| **R-9** | **N16R8 的 GPIO33~37 被 Octal PSRAM 占用** | 引脚规划被迫"绕行"，可用脚变少 | 已在表中避让；**换 N8R2（Quad PSRAM）可释放这 5 个脚** |
| **R-10** | 舵机与电机**共用逻辑电源** | 堵转/浪涌导致 3.3V 轨跌落 → MCU 复位（节点整块掉线） | 分轨供电 + 独立 5V/5A + 肖特基隔离 + 共地；示波器验证 3.3V 轨跌落 < 100 mV |
| **R-11** | **PC13 / PC14 / PC15 灌电流能力很弱** | 板载 LED 之外的负载（如直接驱动蜂鸣器）可能拉低电平或损坏 | 仅作信号或小电流指示；**不要**用它们驱动蜂鸣器/继电器 |

### 上电前逐项核对（打印出来打勾）

- [ ] 三块板的 **CAN_H / CAN_L / GND** 已焊接或压接，且**两端各一只 120Ω**（节点二不装）
- [ ] TJA1050 按 §9.1 处理：**RXD 先串 1kΩ**，TXD 直连；示波器核对高电平幅度
- [ ] 逻辑轨与**动力轨独立供电**，两轨**共地**，舵机电源串肖特基 + 220µF
- [ ] 模拟模块（热敏/光敏/红外）确认供电 3.3V，**AO 不超 VDD+0.3V**（这 10 个 ADC 脚不是 5V 容忍，见 §9.2）
- [ ] **SWD 的 SWDIO/SWCLK 未接任何负载**，排针已引出
- [ ] 按键已使能内部上拉（GPIO8/12/47 复位后悬空，见 R-2），**复位期间用万用表确认按键为高电平**
- [ ] **GPIO0 / GPIO3 / GPIO45 / GPIO46 上无强驱动或外部上下拉**（会改变启动模式 / VDD_SPI 电压）
- [ ] 按键/编码器已验证无短路；蜂鸣器确认低电平有效（不要一直响）
- [ ] 电机与舵机**先不接**，只测 CAN 与传感器，避免动力干扰掩盖通信问题
- [ ] 先 125 kbps 点对点通，再升 500 kbps；用逻辑分析仪确认 **SPI2 时钟（GPIO16）** 与 I²S 波形正常

## 七、采购侧影响（引脚决定的硬约束）

| 决策点 | 结论 | 影响的引脚 |
| --- | --- | --- |
| **模组型号** | ⭐ 若能换 **N8R2（Quad PSRAM）**，释放 GPIO33~37，引脚规划立刻宽松 | GPIO33~37 |
| 必须**坚持 WROOM-1** | 买 WROOM-2 会让 GPIO47/48 变成 1.8V 域，本表作废 | GPIO47、GPIO48 |
| **节点 MCU 换 CBT6（128KB）** | 引脚**完全兼容**，本地表无需改动，但能给 OTA 双区留出空间 | 全部（无变化） |
| 若把 NTC 换 **DS18B20 / SHT30** | 释放 PA0 的 ADC；SHT30 走 I²C1（PB6/PB7），DS18B20 走单总线（需一个 GPIO + 4.7k 上拉） | PA0、PB6/PB7 |
| 若把光敏换 **BH1750** | 直接输出 lux，释放 PA0/PA1；走 I²C1（PB6/PB7） | PA0、PA1、PB6/PB7 |
| 加**编码器做闭环** | 需要 TIM 编码器模式，**必须重新分配引脚**（见 R-8） | PA0/PA1 或 PA6/PA7 |
| 加**电流采样（INA219/ACS712）** | INA219 走 I²C1；ACS712 需一个 ADC 通道 | PB6/PB7 或 PA4/PA5 |

## 八、待核实项（诚实标注）

以下条目**尚未经官方数据手册逐一确认**，下板前需自行查证，本文不代为断言：

1. **GPIO16 作 SPI2_SCK 是否存在已知限制**。检索中遇到一条社区报告（ESP32-S3 上 GPIO16 用作按键失效），**未经官方文档证实，也未验证其适用范围**；本项目把 GPIO16 用作 SPI2 的 SCK（主模式输出），与"作输入/按键"不是同一场景，但**首板上电应优先用逻辑分析仪确认 SPI2 时钟正常**。
2. **ESP32-S3 复位期间的上电毛刺清单**是否包含本项目用到的 I²S/SPI 引脚（GPIO10~18、21）——指南中列出的毛刺引脚为 GPIO1~14、XTAL_32K_P/N、GPIO17~20，**GPIO10~14、17~18 落在其中**，需确认是否影响 W25Q64（SPI2）与 I²S 从设备的初始化时序。
3. **ROM 代码日志打印在 GPIO46 上的电平极性**（哪一电平使能打印）——本次未取到数据手册正文表格，属未证实。
4. **Blue Pill 板上 PA11/PA12 的 USB 相关元件**（上拉电阻/跳线）是否会干扰 CAN（R-6）——需按实物核对。
5. **PC13/PC14/PC15 的具体灌电流上限**——已知"很弱"，但具体数值需查 DS5319 的电气特性表。

### 9.1 ESP32-S3（依据 ESP-IDF 文档 + 乐鑫硬件设计指南）

| **strapping 引脚清单** | 仅 **GPIO0 / GPIO3 / GPIO45 / GPIO46** 四个；**GPIO8、GPIO9 不是** | [ESP-IDF GPIO & RTC GPIO（ESP32-S3）](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/peripherals/gpio.html)、[硬件设计指南 Schematic Checklist](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/schematic-checklist.html) |

### 9.2 STM32F103C8T6（依据 RM0008 Rev 21 + DS5319 Rev 20）

| 事实 | 结论 | 依据（章节/表号） |
| --- | --- | --- |
| **CAN1 可用引脚（LQFP48）** | 只有两种：**PA11/PA12**（默认，pin 32/33）或 **PB8/PB9**（`CAN_REMAP=10`，pin 45/46）。**PD0/PD1 在 48 脚封装不存在**，且 Port D 的 CAN 重映射在 36/48/64 脚封装**被明文禁止** | RM0008 §9.3.3 + Table 34（p.176）注3；§9.4.2 bits 14:13（p.185） |
| PB8/PB9 的代价 | 与 **I²C1 重映射**、**TIM4_CH3/CH4** 冲突（本项目若换 BH1750 走 I²C1 需注意） | DS5319 Table 5（p.32/33） |
| **PA15 / PB3 / PB4 释放为 GPIO** | 开 AFIO 时钟 → 写 `AFIO_MAPR`(0x40010004) bits 26:24 **`SWJ_CFG = 010`**（关 JTAG-DP、留 SW-DP）→ 再配 GPIO。**SWD 仍完全可用** | RM0008 §9.4.2 bits 26:24（p.185）、§31.4.3/§31.4.4、Table 220（p.1083） |

### 9.3 由上述事实推出的两条接线纪律

1. **ADC 引脚（PA0~PA7 / PB0 / PB1）即使标称 FT 也不要在模拟模式下接 5V** —— "FT/5V 容忍"只对数字输入成立。
2. **strapping 脚（GPIO0/3/45/46）上不要挂强驱动负载或外部上下拉** —— 它们决定启动模式与 VDD_SPI 电压，被外部电路拉偏会导致"程序不跑"或 1.8V/3.3V 域错乱。
