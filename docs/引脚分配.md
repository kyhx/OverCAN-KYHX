## 一、分配原则（先定规则，再填表）


| #  | 原则                                                           | 理由                                                          |
| -- | -------------------------------------------------------------- | ------------------------------------------------------------- |
| P1 | **SWD（PA13/PA14）永不占用**                                   | 节点无 USART 时它是唯一的烧写与调试通道；丢了就要拆板接复位线 |
| P2 | **CAN 用芯片默认引脚**（STM32 用 PA11/PA12，ESP32 用 GPIO4/5） | 避免重映射带来的 AFIO 配置与可移植性负担，减少一处出错点      |
| P3 | **定时器资源按用途隔离**：舵机/电机 PWM 各占独立定时器         | 同定时器改频率会互相影响；车身类执行器不应共享时基            |
| P4 | **ADC 引脚绝不接 5V**（即使标称 FT 的脚）                      | 模拟模式下不得超过 VDDA，这是强制项不是优化项                 |
| P5 | **strapping / 启动相关引脚不接按键或强驱动负载**               | 复位瞬间被拉低会改变启动模式（详见风险表 R-1/R-2）            |
| P6 | 优先把**外设固定在硬件外设引脚**上，其余信号用普通 GPIO        | 便于后续换 MCU 或重映射                                       |
| P7 | 每块板**至少留 1 个可用 GPIO**                                 | 现场调试/加装指示灯的救命脚                                   |
| P8 | 引脚分配**只写在配置头文件**里                                 | 换板（C8T6→CBT6）或改板时一处生效                            |

**电气前提**（与引脚强相关，必须一并满足）：

- **逻辑电平**：ESP32-S3 与 STM32 均为 3.3V；TJA1050 是 **5V 器件** → 收发器接 5V 轨，RXD/TXD 电平处理见 [项目文档.md](./项目文档.md) §9.1。
- **供电分轨**：逻辑轨 3.3V/5V 与动力轨（电机 VM、舵机 5V）**独立供电 + 共地**。
- **CAN 物理层**：总线两端各 120Ω（建议分裂终端 2×60Ω+4.7nF），CAN_H/L/GND **焊接或压接**，支线 <0.3m。

### 2.2 不可用 / 慎用引脚（分配表的边界）


| 引脚                                | 状态         | 原因                                                                                                      |
| ----------------------------------- | ------------ | --------------------------------------------------------------------------------------------------------- |
| **GPIO33 ~ GPIO37**                 | ❌**不可用** | N16R8 的**Octal PSRAM** 占用（33=SPIIO4 … 37=SPIDQS）。**若改用 Quad PSRAM 型号（N8R2）这 5 个脚即空闲** |

> 本项目无大词汇量语音模型，2MB PSRAM 足够，这笔账很划算（详见 §6 的采购决策）。

已用 15 个（CAN 2 + I²C 2 + I²S 5 + SPI 4 + 编码器 2 + 按键 3 = 18 个信号，其中编码器与按键不共用）→ 实际占用
**GPIO1、2、4、5、6、7、8、10、11、12、13、14、15、16、17、18、21、47**，备用 1 个（GPIO9）。

**引脚占用汇总**：GPIOA 用 PA0/PA1/PA6/PA9/PA10/PA11/PA12/PA13/PA14；
GPIOB 用 PB12/PB13/PB14/PB15。**无冲突、无重复占用**。

> **电机 B 是否保留？** TB6612 芯片本身是双通道，但**实物只接了一路**。
> HAL 里刻意**保留 `NODE1_MOTOR_B` 枚举值**、由端口层**静默忽略**：
> 业务层（掉线安全态）按"两台电机"的模型同时下发是**正确的抽象**，
> 删掉枚举会迫使业务层写 `#if` 分支——把硬件差异泄漏进业务逻辑，正是分层要避免的。

### 3.2 ⚠️ 为什么 PWMA 落在 PB15 就必须回到 TIM1（MOE 坑）

**PB15 在 LQFP48 上只有 `TIM1_CH3N`（互补输出通道）这一个定时器功能**——
TIM4 根本不映射到 PB15（TIM4_CH1/CH2 固定在 PB6/PB7）。引脚一旦定为 PB15，
就必然回到 TIM1，也就必须正面处理当初刻意回避的两件事：

1. **TIM1 是高级控制定时器，输出默认关闭，必须使能 MOE**（BDTR 的 bit15）。
   漏掉它的现象极具迷惑性：寄存器配置全对、定时器在计数、**引脚上却没有波形**。
2. **互补通道要单独启动**：配置用 `HAL_TIM_PWM_ConfigChannel(..., TIM_CHANNEL_3)`，
   但启动必须用 **`HAL_TIMEx_PWMN_Start(..., TIM_CHANNEL_3)`**
   （`HAL_TIM_PWM_Start` 只置主通道 CC3E，不动互补通道 CC3NE）。
   占空比仍由主通道 **CCR3** 决定（CC3NE 只是把 OC3REF 引到 PB15）。
   `HAL_TIMEx_PWMN_Start()` 内部会调 `__HAL_TIM_MOE_ENABLE()`，两件事一并解决。

**验证方式**（不靠读代码，靠反汇编查固件）：
```
HAL_TIMEx_PWMN_Start 内可见：  orr.w r2, r2, #32768  →  str r2, [r3, #68]
                              置 MOE(bit15)            写 BDTR(偏移 0x44)
```

> **通用纪律：引脚决定定时器，不能反推。** 反过来先挑一个"好用的定时器"再找引脚，
> 迟早撞上互补通道、重映射、或与调试口冲突这类硬约束。
> 若将来想省掉上述两条注意事项，把 PWMA 换到 **PA10（TIM1_CH3，非互补）** 或
> **PB6/PB7（TIM4，通用定时器无 MOE 概念）** 即可。

### 4.2 为什么舵机放在 TIM3（PA6）而不是 TIM1（PA8/PA9）

1. **摆脱高级定时器**：TIM1 输出默认关闭，必须 `TIM_CtrlPWMOutputs(TIM1, ENABLE)` 使能 MOE，漏了就是"配置全对但没波形"的经典坑。
2. **定时器隔离**（原则 P3）：舵机 50 Hz 与电机 20 kHz 频率差 400 倍，共享时基会让参数计算互相牵制。
3. **释放 PA8/PA9**：PB 侧还可留作扩展。

> ⚠️ **常见误解澄清**：同一 TIM1 的两路通道**共用时基**，因此"PA8 做 20 kHz 电机 PWM、PA9 做 50 Hz 舵机"是**不成立的**；
> 但"两路都是 50 Hz 舵机"完全没问题。文档早期版本把"同频无冲突"错写成了"必然冲突"，两处都需以本条为准。

## 五、跨板一致性与总线侧

### 5.1 CAN 总线拓扑与终端


| 项     | 规定                                                                             |
| ------ | -------------------------------------------------------------------------------- |
| 速率   | 500 kbps（面包板原型先用**125 kbps**）                                           |
| 采样点 | **87.5%**（STM32：P=9/BS1=6/BS2=1/SJW=1；ESP32：brp=20/tseg_1=6/tseg_2=1/sjw=1） |
| 终端   | **物理两端各 120Ω**（建议分裂终端 2×60Ω + 4.7nF 到地）；中间节点**不加**    |
| 支线   | **< 0.3 m**                                                                      |
| 接线   | CAN_H / CAN_L / GND**必须焊接或压接**，不可用面包板杜邦线                        |
| 布线   | 差分线**绞线**走线，与电机/舵机动力线**分开**                                    |

**三块板在总线上的位置**：核心机（ESP32-S3）与节点一在链路两端（各装一只终端电阻），节点二居中（不装）。
若日后把节点二挪到末端，终端电阻要跟着挪——**终端接的是"线的物理两端"，不是"某块特定的板"**。

### 5.2 I²S 共享时钟（核心机专用）

麦克风（MS4030/INMP441）与功放（MAX98357）**共享 BCLK/WS 时必须挂在同一 I²S 端口**，两条合法路径：


| 方案                                | 引脚数                    | 说明                                                   |
| ----------------------------------- | ------------------------- | ------------------------------------------------------ |
| (a) 单端口全双工，共享 BCLK/WS      | 本节 2.1 表所用（4~5 脚） | 省引脚；需保证 TX/RX 槽位与位宽配置一致                |
| (b) 双端口独立（I2S0 收 / I2S1 发） | 6 脚                      | 更简单，无全双工耦合约束；ESP32-S3 有 2 个 I²S 控制器 |

> INMP441 输出 24 bit 左对齐装在 32 bit 容器里，读取后**必须右移 8 位**，否则音量异常偏小。

### 9.3 由上述事实推出的两条接线纪律

1. **ADC 引脚（PA0~PA7 / PB0 / PB1）即使标称 FT 也不要在模拟模式下接 5V** —— "FT/5V 容忍"只对数字输入成立。
2. **strapping 脚（GPIO0/3/45/46）上不要挂强驱动负载或外部上下拉** —— 它们决定启动模式与 VDD_SPI 电压，被外部电路拉偏会导致"程序不跑"或 1.8V/3.3V 域错乱。
